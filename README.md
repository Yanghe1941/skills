# Skills

A collection of agent skills by [Yanghe1941](https://github.com/Yanghe1941), for Claude Code, OpenClaw and other agents that support `SKILL.md`.
杨鹤的 AI Agent 技能合集，适用于 Claude Code、OpenClaw 等支持 `SKILL.md` 的 Agent。

| Skill | What it does / 功能 | Version | ClawHub |
|---|---|---|---|
| [adaptive-eta](skills/adaptive-eta) | Honest time estimates for long tasks, with overrun alerts and self-calibration / 长任务时间预估、超时提醒与自我校准 | 0.3.0 | [adaptive-eta](https://clawhub.ai/yanghe1941/skills/adaptive-eta) |

## Install / 安装

Via ClawHub:

```bash
clawhub install adaptive-eta
```

Or copy manually (Claude Code) / 或手动复制到 Claude Code：

```bash
git clone https://github.com/Yanghe1941/skills.git
cp -R skills/skills/adaptive-eta ~/.claude/skills/
```
